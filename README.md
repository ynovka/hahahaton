# 🐾 Питомец Финни (PetMe) — Игра по финансовой грамотности для детей

Проект мобильной игры для хакатона Департамента финансов Москвы (для детей 7–11 лет).

## 🚀 Быстрый старт

### Сборка приложения
Требуется **JDK 17+** (рекомендуется встроенный в Android Studio JBR) и Android SDK.

В Windows PowerShell:
```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat assembleDebug
```
Собранный APK: `app/build/outputs/apk/debug/app-debug.apk`

### Запуск тестов логики
```powershell
.\gradlew.bat test
```

## 👥 Инструкция для участников команды
Подробное руководство для каждого члена команды (где лежат твои файлы, как подключать базу данных, куда класть рисунки и как менять тексты):  
👉 **[TEAM_GUIDE.md](TEAM_GUIDE.md)**

- **Человек №1 (Геймдизайнер)**: меняет тексты и баланс в `core/data/GameCatalog.kt`.
- **Человек №2 (Мир и Android)**: движок, комната, карта с параллаксом, сборка.
- **Человек №3 (Экономика и БД)**: подключает Room DB к `GameState` и `GameViewModel`.
- **Человек №4 (Художник)**: складывает ассеты в `app/src/main/res/drawable/`.
- **Человек №5 (Тестировщик / Капитан)**: тестирует билд из `app-debug.apk`.
