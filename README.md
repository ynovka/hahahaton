# 🐾 Питомец Финни (Finny the Pet) — Обучающая веб-игра по финансовой грамотности

Полноценное веб-приложение для детей **7–11 лет** в тактильном **3D пластилиновом стиле (Claymorphism)**, разработанное по требованиям технического задания Департамента финансов г. Москвы.

---

## 🚀 Быстрый запуск игры (В 1 клик)

### Самый простой способ:
- **Дважды кликните по `start_game.bat`** в корне проекта:
  - Автоматически запустит локальный веб-сервер на порту `3000`.
  - Откроет браузер со страницей игры: `http://localhost:3000/`.
- Или запустите в PowerShell: `.\start_game.ps1`.

Не открывайте `index.html` двойным кликом: браузер блокирует скрипты игры при адресе `file:///…`, поэтому кнопки не сработают.

### Через терминал:
```bash
# 1. Установка зависимостей (если не установлены)
npm install

# 2. Запуск сервера разработки
npm run dev

# 3. Сборка оптимизированного релизного бандла
npm run build
```

## 🎨 Особенности и игровой дизайн

### 1. 3D-пластилиновая эстетика (Claymorphism)
- Мягкие скругления, выпуклые объёмные кнопки с приятным тактильным эффектом нажатия («Squash & Stretch»).
- Нежные пастельные цвета, плавные анимации парения пинов над зданиями.
- Процедурный звуковой синтезатор на **Web Audio API**: мгновенный отклик, звон монет, клики кнопок, мурлыканье питомца и победные фанфары без внешних MP3-файлов.
- Праздничный салют из конфетти на Canvas при победах, выполнении заданий и росте питомца.

### 2. Полный игровой мир по ТЗ
- **7 видов питомцев**: Котёнок, Щенок, Лисёнок, Панда, Зайчик, Енотик, Совёнок.
- **14 комбинаций внешности**: 7 видов × 2 варианта окраса (Классический / Пятнистый-полосатый).
- **Интерактивная карта города**:
  - Поддержка вертикального (9:16) и горизонтального (16:9) режимов.
  - 11 интерактивных пинов над зданиями с анимированными бейджиками статуса заданий.
- **11 детальных интерьерных сцен**:
  - **Моя комната**: питомец, уход (покормить, умыть, поиграть), гардероб, распределение бюджета.
  - **7 квартир друзей**: Медвежонок Потап, Белочка Рыжик, Енотик Тёма, Совушка София, Лисичка Алиса, Зайчик Сеня, Щенок Барбос.
  - **Городской Банк**: Бобёр-банкир, копилка и 3 цели накопления.
  - **Лавка Енотика**: продавец, витрина полезных и приятных товаров.
  - **Клиника Заботы**: Доктор Сова, еженедельный профилактический осмотр и витаминные процедуры.

## 📚 Механики финансовой грамотности

1. **Планирование детского бюджета (Правило трёх горшочков)**:
   - 🥣 **Миска и Забота** (Обязательные расходы: еда, гигиена, здоровье).
   - 🎁 **Сундучок Радостей** (Желания: мячики, игрушки, наряды).
   - 🏺 **Копилка на Мечту** (Сбережения: долгосрочные цели).
   - Быстрые пресеты: классическое правило **50/30/20**, «Супер-Копилка», «Поровну».
   - Защита: нельзя выйти в город без составления и утверждения плана; нельзя оставить миску пустой.

2. **3 Мечты питомца (Цели накопления)**:
   - 🏰 *Кошачий/Щенячий Замок* — 100 монет.
   - 🎡 *Весёлая Игровая Площадка* — 150 монет.
   - 🌴 *Райский Уголок с Гамаком* — 200 монет.
   - Прогресс-бар в реальном времени, возможность пополнения и подтверждаемого снятия.

3. **7 Интерактивных развивающих заданий**:
   - Покрывают ключевые темы Единой рамки компетенций:
     1. *Мишка Потап* — Обязательное против желаний (Needs vs Wants).
     2. *Белочка Рыжик* — Регулярные сбережения и правило копилки.
     3. *Енотик Тёма* — Сравнение удельных цен и выгода фасовки.
     4. *Совушка София* — Финансовая безопасность и распознавание мошенников.
     5. *Лисичка Алиса* — Точный расчёт монет без сдачи.
     6. *Зайчик Сеня* — Подушка безопасности на случай непредвиденных трат.
     7. *Щенок Барбос* — Соблюдение праздничного лимита бюджета.
   - Награда: **+20 монет** за каждое решенное задание с защитой от повторного списания.

4. **12 коротких уроков от Подручного**:
   - Помощник объясняет тему простыми карточками до того, как она встретится в задании: бюджет, обязательные траты, желания, сбережения, цели, цена, сдача, безопасность, банк, здоровье, доход и финансовый план.
   - После урока ребёнок видит, где применить знание в городе. Это не просто справка: уроки открывают осмысленный контекст перед диалогами и задачами друзей.

5. **3 Стадии роста питомца**:
   - 🍼 **Малыш** (0–4 очков развития).
   - 🌟 **Подросший** (5–9 очков развития).
   - 👑 **Взрослый** (10+ очков развития).
   - Очки начисляются за осознанные действия: сытость питомца, откладывание монет в копилку, решение задач друзей и уход.

6. **5 Игровых периодов**:
   - Демо-режим позволяет пройти 5 последовательных финансовых циклов без ожидания реальных дней.
   - В конце периода подводится отчёт успехов, выдаются очки роста и начисляются карманные деньги на новый период (+100 монет).

7. **Раздел взрослого (Parental Control & Dashboard)**:
   - Защитный математический барьер для детей (например, `7 × 8 = ?`).
   - Методическое описание образовательных целей.
   - Статистика прогресса ребёнка (периоды, накопления, решенные задачи).
   - Кнопка полного сброса демонстрационных данных.

## 🛠️ Архитектура и технологии

- **Core**: Vanilla HTML5 + ES Modules JavaScript (без раздутых внешних библиотек).
- **Styling**: Чистый CSS3 с переменными, сложной пластилиновой тенью (Claymorphism), flexbox и grid layout, адаптивность от 360px (смартфоны) до 4K (десктоп).
- **Аудио**: Процедурный синтезатор на Web Audio API (`src/audio.js`).
- **Сборка**: Быстрый Vite (`vite build` собирает бандл за ~130 мс).
- **Хранение данных**: `localStorage` с автоматическим сохранением состояния игры при каждом действии.
- **Kid-Safe**: Никаких сборов персональных данных, трекеров, реальных покупок или рекламы.
