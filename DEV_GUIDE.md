# Руководство разработчика: «Питомец Финни»

Проект — образовательная игра на JavaScript и Vite, упаковываемая в автономный Android APK через Capacitor.

## Запуск в браузере

1. Дважды нажмите `start_game.bat`.
2. Игра откроется по адресу `http://localhost:3000/`.

Не открывайте `index.html` двойным кликом. При адресе `file:///…` браузер блокирует модули JavaScript, поэтому кнопки и сохранения не работают.

Альтернатива через терминал:

```powershell
npm install
npm run dev
```

Для проверки веб-сборки:

```powershell
npm run build
```

## Сборка Android APK

Сборка автономного debug APK выполняется одной командой:

```powershell
.\build_apk.ps1
# или:
npm run build:apk
# или двойным кликом:
build_apk.bat
```

Собранный установочный APK сохраняется в:
- `FinnyPet-debug.apk` (в корне проекта)
- `android/app/build/outputs/apk/debug/app-debug.apk`

## Структура проекта

| Путь | Что находится внутри |
| --- | --- |
| `index.html` | экраны игры и модальные окна |
| `src/state.js` | единое состояние, экономика и сохранение в `localStorage` |
| `src/data.js` | питомцы, друзья, уроки, товары и задания |
| `src/ui.js` | отрисовка экранов, переходы и обработчики действий |
| `src/styles/` | стили стартового экрана, карты, комнат и модальных окон |
| `public/assets/` | фоны, персонажи, предметы и карта |
| `scripts/generate_pet_variants.py` | создание временных пятнистых/полосатых вариантов питомцев |

## Правила командной работы

- Не редактируйте один файл одновременно с другим участником без договорённости.
- Перед изменением механики читайте `src/state.js`; интерфейс не должен сам менять монеты, дружбу или прогресс.
- Новые задания друзей добавляйте в `src/data.js`, а награду выдавайте только через методы `gameState`.
- Новые PNG кладите в `public/assets/`; пути к ним начинаются с `assets/`.
- После изменений запускайте `npm run build` и вручную проверяйте нужный игровой путь в браузере.

## Что нужно художнику

Сейчас друзья и сотрудники нарисованы прямо внутри фонов комнат. Чтобы они двигались независимо, нужны прозрачные PNG или короткие спрайт-листы: idle-анимация из 2–3 кадров для героя, каждого друга и трёх работников. Размер и прозрачный фон важнее фиксированного разрешения.

## Сохранения

Игра сохраняет прогресс в браузере автоматически. Для чистого теста используйте в игре: `☰ → Настройки → Начать игру с начала`.
